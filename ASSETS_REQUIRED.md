# Asset locations

Recover these binary files and matching .meta files from the team's corrected Unity project before opening this source checkout in Unity.

- `Assets/Tide/Resources/Tide/Anim/`: character and effect frames.
- `Assets/Tide/Resources/Tide/Art/`, `Ending/`, `Timeline/`: story backgrounds, title graphics and scene art.
- `Assets/Tide/Resources/Tide/Guides/`, `Maps/`, `UI/`: hints, tile graphics and UI art.
- `Assets/Tide/Resources/Tide/Sound/`: music and sound effects.
- Any original map-source images used to modify the tilemaps under `Assets/Tide/MapSource/`.

Keep original paths and Unity GUIDs when adding the team's approved asset copies. The repository is suitable for inspecting the game source and serialized scene data. Play the published Windows ZIP for the complete presentation.
